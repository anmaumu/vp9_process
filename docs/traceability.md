## Coverage rules

- `..`はID rangeの省略記法であり、range内全IDを含む。
- 実装PRでは該当`INT-*`と`TEST-*`をdescriptionへ記載する。
- requirement追加時は同じchangeでAC、INT、TEST、design-modelを更新する。
- test未実装はIDを削除せずStatusを`PROPOSED`または`TBD`にする。

## Machine coverage index

省略rangeを展開した完全なID index。quality gateはこのindexと各正本文書の集合一致を検査する。
